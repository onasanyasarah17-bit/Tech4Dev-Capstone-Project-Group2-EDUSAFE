# 📚 About the Project

EduSafe is a responsive web-based school management platform developed as part of the **Tech4Dev Capstone Project**.

The application focuses on creating a modern, user-friendly and secure learning environment by providing authentication, centralized access to information, notifications and AI-powered assistance.

The project follows responsive web design principles, ensuring accessibility across desktop, tablet and mobile devices.

---

# ❗ Problem Statement

Many schools struggle with:

- Centralized student information management
- Secure user authentication
- Effective communication
- Easy access to academic resources

These challenges often lead to poor collaboration and fragmented user experiences.

---

# 🎯 Project Objectives

The EduSafe platform aims to:

- Provide secure authentication
- Improve communication between users
- Centralize school information
- Offer AI-powered assistance
- Deliver a responsive user experience across all devices

# ▶ Running the Project

This project requires no installation.

Simply:

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click **index.html**
4. Select **Open with Live Server**.
