# 📚 About the Project

EduSafe is a responsive web-based school management platform developed as part of the **Tech4Dev Capstone Project**.

The application focuses on creating a modern, user-friendly and secure learning environment by providing authentication, centralized access to information, notifications and AI-powered assistance.

The project follows responsive web design principles, ensuring accessibility across desktop, tablet and mobile devices.

## Project Overview

EduSafe is a comprehensive educational management platform designed to bring students, teachers, and parents together in a single, intuitive interface. It provides a safe, modern, and fully responsive environment for managing academic progress, attendance, communication, and resources.

This capstone project addresses real-world challenges in educational administration by providing:
- Role-based access and dashboards for students, teachers, and parents
- Real-time monitoring of academic performance
- Centralized resource management
- Secure communication channels
- Mobile-friendly, professional design

## Vision & Mission

**Our Vision**: To create an inclusive, safe, and efficient educational ecosystem that empowers every stakeholder to succeed.

**Our Mission**:
- Enhance communication between students, teachers, and parents
- Simplify academic management and administration
- Provide real-time visibility into academic progress
- Ensure accessibility across all devices
- Maintain high standards of design and user experience

## Features

### Student Dashboard
- **Home Overview**: Quick stats, upcoming classes, and quick actions
- **Courses Management**: Browse and enroll in available courses
- **Attendance Tracking**: View detailed attendance records
- **Grades & GPA**: Monitor academic performance
- **AI Study Buddy**: Integrated AI-powered study assistant
- **Online Quizzes**: Take practice quizzes for better learning

### Teacher Dashboard
- **Overview Stats**: Total students, active courses, pending grading, today's schedule
- **Classes Management**: Manage classes and course materials
- **Student Roster**: View and communicate with students
- **Assignments**: Create, manage, and grade assignments
- **Resources**: Upload and share educational resources

### Parent Dashboard
- **Student Selector**: Switch between multiple children
- **Overview Stats**: Enrolled courses, attendance, GPA
- **Attendance Monitoring**: View detailed attendance for each course
- **Grade Checks**: Monitor academic performance
- **Announcements**: Stay updated with school news
- **Quick Actions**: Contact teachers, download reports

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with modern gradients and responsive design
- **Icons**: Font Awesome 6.5.0
- **Storage**: LocalStorage API for user sessions and data persistence
- **AI Integration**: Custom ai-chat.js module for AI study assistant
- **Design Principles**: Mobile-first, responsive, modern UI/UX

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Python (for running the local server)

### Installation
1. Clone or download the project files to your local machine
2. Navigate to the project directory
3. Start a local server:

   ```bash
   python -m http.server 8000
   ```

4. Open your browser and go to `http://localhost:8000`

### Usage
1. **Splash Page**: Start here to explore the platform
2. **Signup/Login**: Create an account or log in (choose your role: Student, Teacher, or Parent)
3. **Dashboard**: You'll be redirected to your role-specific dashboard
4. **Logout**: Use the logout button in any dashboard to end your session
